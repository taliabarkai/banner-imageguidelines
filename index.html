How it works

Turn on the homepage sections you need, set each one's layout in Site configuration, then open Designer for the image sizes. Specs collects everything to send on. Your work is saved in this browser only.

Homepage order

Sections always appear in this order on every brand. You can't move them, only turn them on or off.

How image sizes are worked out

  • The page is 390px wide on mobile and 1440px on desktop. A tile's width comes from the tiles per row, the gap and the page margin.
  • Images are exported at 2× the tile width on mobile and 1.5× on desktop, rounded up to the nearest 10px, so they stay sharp.
  • Never narrower than 1000px, or 800px when 4 or more tiles sit across on desktop.
  • A full-width banner with 1 tile on desktop is always 2880px wide for desktop.
  • The height comes from the aspect ratio. With the same ratio on both devices, one file covers both, at the larger size.

Three rules

  • Put words in live text, not in the image. Live text stays sharp and can change without a new export.
  • Keep one shape per banner. Tiles with different shapes in the same banner get cropped.
  • A different desktop ratio means two files per tile. If one is missing, that tile is hidden on that device.
